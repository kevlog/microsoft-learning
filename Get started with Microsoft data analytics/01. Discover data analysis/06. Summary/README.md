# Get Started with Microsoft Data Analytics

## Modul: Discover Data Analysis

Modul ini merupakan pengantar penting untuk memahami peran, proses, dan kolaborasi dalam analisis data menggunakan Microsoft Power BI. Di sini kamu akan belajar mengapa analisis data penting, siapa saja yang terlibat, dan apa saja tugas utama seorang data analyst.

---

## 🧠 Ringkasan Pembelajaran

### 1. Introduction
- Kita hidup di era ledakan data: transaksi, sensor, media sosial, dan banyak lagi.
- Bisnis modern mengandalkan data untuk bertahan dan berkembang.
- **Tantangan utama:** bagaimana mengubah data mentah menjadi **informasi bermakna**.
- **Solusi:** Data harus diolah, dianalisis, dan disampaikan dalam bentuk cerita yang informatif.

Contoh pada bisnis retail:
- Melacak inventaris
- Mendeteksi pola pembelian
- Memprediksi tren
- Optimasi harga
- Deteksi penipuan

### 2. Overview of Data Analysis
- Analisis data mencakup: **identifikasi, pembersihan, transformasi, pemodelan, visualisasi**.
- Tujuannya: mendapatkan insight yang berguna untuk pengambilan keputusan.

#### 📊 Jenis-jenis Analytics:
1. **Descriptive Analytics** – Apa yang terjadi?  
   Contoh: Laporan penjualan tahunan.
2. **Diagnostic Analytics** – Kenapa itu terjadi?  
   Contoh: Penurunan penjualan karena kurangnya promosi.
3. **Predictive Analytics** – Apa yang akan terjadi?  
   Contoh: Prediksi tren berdasarkan data historis.
4. **Prescriptive Analytics** – Apa yang sebaiknya dilakukan?  
   Contoh: Rekomendasi diskon berdasarkan analisis perilaku pelanggan.
5. **Artificial Intelligence (AI)** – Insight otomatis dari data dalam skala besar.

### 3. Roles in Data
Dalam proses analisis data, ada berbagai peran:

- **Business Analyst**: Fokus pada kebutuhan bisnis dan interpretasi laporan.
- **Data Analyst**: Menyiapkan, memodelkan, memvisualisasi, dan menganalisis data untuk membuat laporan.
- **Data Engineer**: Menyediakan dan mengelola infrastruktur data (database, pipeline).
- **Analytics Engineer**: Mengelola semantic model dan data warehouse, jembatan antara engineer dan analyst.
- **Data Scientist**: Melakukan eksperimen lanjutan, machine learning, dan prediksi berbasis data.

> Semua peran ini bekerja sama agar insight dari data dapat ditemukan secara efisien dan akurat.

### 4. Tasks of a Data Analyst
Lima tugas inti seorang data analyst:

#### 🔧 1. Prepare (Menyiapkan Data)
- Membersihkan, memprofilkan, dan mengamankan data.
- Transformasi tipe data dan format.
- Menghilangkan duplikasi dan kesalahan.
- Menjamin kualitas dan privasi data.

#### 🧩 2. Model (Membangun Model Data)
- Menghubungkan tabel (relasi) dan membuat metrik perhitungan.
- Model yang efisien = laporan yang cepat, akurat, dan mudah dipelihara.

#### 📊 3. Visualize (Visualisasi Data)
- Mengubah data menjadi grafik dan dashboard yang komunikatif.
- Cerita yang baik membantu stakeholder memahami data dan membuat keputusan.
- Power BI menyediakan fitur AI dan Copilot untuk membantu proses ini.

#### 🔍 4. Analyze (Menganalisis Data)
- Menemukan insight, pola, dan tren.
- Menggunakan fitur Power BI dan integrasi AI (Azure ML, Copilot, Quick Insights).

#### 📁 5. Manage (Mengelola Aset Data)
- Mengelola dashboard, laporan, workspace, dan semantic model di Power BI.
- Menjamin keamanan, distribusi, dan akses ke data.
- Menghindari duplikasi dan silo data dengan model yang dibagikan dan tersertifikasi.

## 🧾 Kesimpulan Modul
- Data analyst memainkan peran vital dalam mengubah data menjadi insight yang berdampak.
- Pekerjaan mereka memastikan keputusan bisnis dibuat berdasarkan informasi yang valid dan terpercaya.
- Mereka bekerja erat dengan peran lain seperti data engineer dan data scientist.
