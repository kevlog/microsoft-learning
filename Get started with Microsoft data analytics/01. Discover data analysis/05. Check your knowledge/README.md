1. Which data role enables advanced analytics capabilities specifically through reports and visualizations?
✅ Jawaban: Data analyst

Penjelasan:
Data analyst adalah peran yang secara khusus fokus pada pembuatan laporan dan visualisasi. Mereka menggunakan tools seperti Power BI untuk:

Membersihkan dan memodelkan data

Membuat visualisasi

Mengaktifkan kemampuan analitik lanjut melalui laporan (misalnya: AI visual, quick insights)

2. Which data analyst task has a critical performance impact on reporting and data analysis?
✅ Jawaban: Model

Penjelasan:
Tahap modeling sangat penting karena:

Struktur model yang buruk bisa memperlambat refresh data dan performa laporan

Model yang baik membuat analisis lebih akurat dan efisien

Tahap ini menentukan relasi antar data dan metrik perhitungan

3. Which one of the following options is the most important key benefit of data analysis?
✅ Jawaban: Informed business decisions

Penjelasan:
Tujuan utama dari data analysis adalah untuk memberikan dasar pengambilan keputusan yang tepat (informed).
Dengan analisis data, perusahaan bisa:

Mengetahui tren pasar

Memahami perilaku pelanggan

Mengoptimalkan strategi bisnis
