🧾 Ringkasan Materi
Microsoft Fabric adalah platform analitik end-to-end yang menyatukan seluruh proses data dalam satu lingkungan terpadu. Platform ini memungkinkan kolaborasi antara profesional data dan pelaku bisnis dalam proyek data.

🛠️ Apa yang Ditawarkan Microsoft Fabric?
Fabric menyediakan satu lingkungan terintegrasi untuk:

📥 Ingest (Mengambil data)

🗃️ Store (Menyimpan data)

⚙️ Process (Memproses data)

📊 Analyze (Menganalisis data)

Semua proses tersebut dapat dilakukan dalam satu alur tanpa perlu berpindah platform.

👤 Siapa Pengguna Microsoft Fabric?
Citizen data practitioners
(Pengguna bisnis atau analis non-teknis yang ingin membuat insight dari data)

Professional data practitioners
(Seperti data engineer, data scientist, BI developer, dsb.)

Fabric mendukung kedua jenis pengguna, sekaligus terintegrasi dengan berbagai tools yang dibutuhkan bisnis untuk mengambil keputusan.

🧱 Layanan Utama dalam Microsoft Fabric:
Layanan	Fungsi Utama
🔧 Data Engineering	Membangun pipeline dan pemrosesan data skala besar
🔗 Data Integration	Menggabungkan data dari berbagai sumber
🏢 Data Warehousing	Penyimpanan data dalam format yang efisien untuk analisis
📈 Real-time Intelligence	Menganalisis data secara langsung (real-time)
🧪 Data Science	Melakukan eksperimen, modeling, dan prediksi
📊 Business Intelligence	Visualisasi dan pelaporan insight bisnis

Modul ini merupakan pengantar untuk mengenal Microsoft Fabric, siapa saja yang dapat menggunakannya, dan bagaimana setiap layanan saling terintegrasi untuk membentuk proses analitik menyeluruh.
