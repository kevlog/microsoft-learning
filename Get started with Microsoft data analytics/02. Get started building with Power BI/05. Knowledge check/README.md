🧠 Knowledge Check
1. What is the common flow of activity in Power BI?
✅ Jawaban:
Create a report in Power BI Desktop, share it to the Power BI service, and interact with reports in the service and Power BI Mobile.

📌 Penjelasan:
Alur kerja umum Power BI dimulai dari Power BI Desktop (untuk menghubungkan dan memodelkan data serta membuat laporan), lalu dipublikasikan ke Power BI Service (untuk manajemen dan distribusi), dan dapat diakses/interaksi melalui Power BI Mobile.

2. Which of the following are building blocks of Power BI?
✅ Jawaban:
Semantic models and visualizations.

📌 Penjelasan:
Dua komponen inti (building blocks) Power BI adalah:

Semantic models: Struktur data, relasi, dan kalkulasi

Visualizations: Grafik atau komponen visual yang menyajikan insight dari model tersebut

3. What is a collection of reports and dashboards called in Power BI?
✅ Jawaban:
An app.

📌 Penjelasan:
App di Power BI adalah kumpulan dari beberapa laporan (reports) dan dashboard yang disajikan secara terorganisir kepada pengguna akhir. Ini adalah cara terbaik untuk membagikan konten secara profesional dan terstruktur dalam organisasi.
