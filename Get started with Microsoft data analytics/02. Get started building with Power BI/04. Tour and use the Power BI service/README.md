🌐 Mengenal Power BI Service
Power BI Service adalah platform berbasis web yang menyederhanakan pengelolaan, distribusi, dan interaksi data analitik melalui pengalaman pengguna yang intuitif. Di sinilah kamu bisa:

Mengatur laporan dan dashboard

Membagikan insight ke pengguna lain

Menjadwalkan pembaruan data

Membuat aplikasi laporan untuk konsumen

📁 1. Organisasi Item dengan Workspace
Workspace adalah wadah utama untuk mengatur konten di Power BI Service.

Setiap pengguna memiliki My Workspace (ideal untuk testing pribadi).

Untuk membagikan konten secara profesional, gunakan shared workspace yang bisa diakses oleh tim/organisasi.

🧪 2. Jelajahi Contoh Laporan (Sample Reports)
Jika belum membuat laporan sendiri:

Kamu bisa membuka laporan contoh melalui menu Learn.

Laporan akan dimuat ke My Workspace agar bisa kamu eksplorasi secara pribadi.

Cocok untuk belajar struktur laporan dan interaktivitas visual.

🚀 3. Distribusi Konten dengan App
Di dalam Workspace, kamu bisa membuat App untuk membagikan laporan & dashboard ke audiens dengan tampilan yang rapi.

App memungkinkan:

Pemilihan konten yang ingin ditampilkan

Pengaturan audiens

Kontrol versi konten (diperbarui hanya ketika kamu klik Update App)

📌 Catatan: Memberi akses ke App lebih aman daripada membagikan seluruh Workspace atau laporan satu per satu.

🧩 4. Template Apps (Aplikasi Siap Pakai)
Template apps adalah aplikasi laporan siap pakai yang bisa dikustomisasi dengan data kamu sendiri.

Bisa diakses melalui:
➜ Klik Apps > Get apps > Template apps

📌 Contoh:
Jika kamu memakai GitHub di organisasi, kamu bisa langsung pakai GitHub Template App yang berisi insight seperti Top Contributors, Pull Requests, dsb — tanpa membangun laporan dari awal.

🔁 5. Refresh Semantic Model
Agar laporan selalu menampilkan data terkini:

Kamu bisa mengatur jadwal pembaruan otomatis (Scheduled Refresh) di Power BI Service.

Atau melakukan refresh manual (On-demand) jika perlu segera diperbarui.

Opsi pengaturan mencakup:

Frekuensi pembaruan

Waktu spesifik

Notifikasi error
