📘 Modul: Introduction to End-to-End Analytics Using Microsoft Fabric
🧭 Learning Path: Explore End-to-End Analytics with Microsoft Fabric

🧾 Ringkasan Materi
Microsoft Fabric menyederhanakan solusi analitik berskala besar yang umumnya kompleks, terfragmentasi, dan mahal, menjadi sebuah platform terpadu dan mudah digunakan.

🛠️ Fitur Utama Microsoft Fabric:
🗃️ OneLake - Penyimpanan Terpusat
OneLake adalah arsitektur penyimpanan utama Fabric.

Dibangun di atas Azure Data Lake Storage (ADLS).

Mendukung format terbuka: Delta, Parquet, CSV, JSON.

Semua mesin komputasi Fabric otomatis menyimpan datanya di OneLake.

Shortcuts memungkinkan akses ke data eksternal (cloud lain) tanpa duplikasi.

Memastikan konsistensi data tanpa perlu copy atau pemindahan fisik.

📌 Keuntungan:

Tidak perlu memindahkan data

Akses lintas wilayah & cloud

Pengelolaan biaya lebih efisien

📦 Workspaces - Kontainer Logis
Digunakan untuk mengatur dan mengelola data, laporan, model, dan aset lainnya.

Masing-masing workspace memiliki kontrol akses dan perizinan sendiri.

Mendukung kolaborasi antar tim tanpa kompromi keamanan.

🔧 Fitur tambahan:

Pengelolaan resource komputasi

Integrasi Git untuk version control

🛡️ Administration dan Governance
Semua pengaturan administrasi tersedia di Admin Portal.

Pengelolaan:

Grup dan izin akses

Sumber data & gateway

Pemantauan performa dan penggunaan

Integrasi API & SDK untuk otomatisasi

🗂️ OneLake Catalog:

Memberikan informasi penting terkait:

Label sensitivitas

Metadata

Status refresh data

Digunakan untuk menganalisis dan meningkatkan kepatuhan terhadap tata kelola data.
