🧪 1. Apa itu Data Analysis?
Sebelum data bisa "bercerita", data perlu diproses terlebih dahulu agar siap digunakan.
👉 Data analysis adalah proses:

Mengidentifikasi

Membersihkan

Mengubah (transform)

Memodelkan data

Tujuannya: Menemukan informasi yang berguna dan bermakna, lalu dituangkan dalam laporan untuk mendukung pengambilan keputusan.

🧱 2. Mengapa Data Analysis Penting?
Karena dunia semakin berorientasi pada data, kemampuan untuk bercerita melalui data menjadi hal yang sangat penting, baik untuk bisnis besar maupun kecil.

Namun kenyataannya, banyak bisnis masih belum memanfaatkan potensi data secara maksimal.

📌 Dengan data analysis, bisnis bisa:

Menilai kepuasan pelanggan

Melakukan riset pasar dan produk

Mendeteksi tren

Mengambil keputusan yang lebih tepat

🔍 3. Jenis-Jenis Analisis Data
Proses analisis data terbagi menjadi beberapa kategori utama:

📌 A. Descriptive Analytics (Analisis Deskriptif)
Menjawab: "Apa yang sudah terjadi?"

Menggunakan data historis untuk memberikan gambaran umum

Contoh: Laporan penjualan tahunan, KPI (Key Performance Indicator), ROI

📌 B. Diagnostic Analytics (Analisis Diagnostik)
Menjawab: "Mengapa itu terjadi?"

Menggali penyebab dari perubahan yang terjadi

Langkah umum:

Temukan kejanggalan (anomaly)

Kumpulkan data yang relevan

Gunakan teknik statistik untuk menemukan penyebabnya

📌 C. Predictive Analytics (Analisis Prediktif)
Menjawab: "Apa yang akan terjadi nanti?"

Menggunakan data historis dan teknik statistik/ML seperti:

Regresi

Decision tree

Neural network

📌 D. Prescriptive Analytics (Analisis Preskriptif)
Menjawab: "Apa yang harus kita lakukan?"

Memberikan saran atau tindakan terbaik untuk mencapai target

Sering menggunakan machine learning

Membantu bisnis membuat keputusan di tengah ketidakpastian

📌 E. Artificial Intelligence (AI)
AI membantu menganalisis data secara otomatis dan lebih cepat

Contoh kemampuan AI:

Mengenali pola data

Menyediakan insight

Membuat rekomendasi visualisasi

Natural language processing (NLP), pengenalan gambar, dsb

🛍️ 4. Contoh Nyata dalam Dunia Ritel
Misalnya:

Gunakan descriptive analytics untuk melihat pola pembelian tahun lalu

Lihat apakah produk tertentu laku karena kampanye marketing atau tren sosial

Gunakan hasilnya untuk memutuskan apakah produk itu harus tetap dijual

📌 Analisis ini bisa membantu ritel memutuskan stok, harga, dan strategi penjualan.

🧾 5. Pentingnya Data yang Dapat Dipercaya
"Trust your data"
Untuk bisa membuat keputusan dari data, data harus bersumber dari tempat yang terpercaya.

Analisis data:

Mengubah data mentah menjadi sesuatu yang mudah dipahami

Membantu bisnis merasa yakin atas keputusan yang mereka buat

👨‍💼 6. Peran Penting Data Analyst
Data analyst tahu:

Cara memilih data yang relevan

Cara merapikan dan menyederhanakan informasi kompleks

Cara menyampaikan insight yang jelas dari “banjir data”
