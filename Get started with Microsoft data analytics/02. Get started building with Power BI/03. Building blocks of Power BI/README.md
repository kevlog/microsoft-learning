🧱 Komponen Utama (Building Blocks) Power BI
Power BI dibangun atas dua komponen inti:

Semantic Model (Model Semantik)

Visualizations (Visualisasi)

Keduanya merupakan fondasi dari laporan yang kamu buat di Power BI. Kamu akan membangun model semantik, lalu menggunakan visual untuk menyampaikan insight data secara interaktif.

🔷 1. Membangun Semantic Model
Semantic model mencakup:

Sumber data yang saling terhubung

Proses transformasi (cleaning, shaping)

Relasi antar tabel

Perhitungan atau formula (misal DAX)

Langkah-langkah:

Connect: Sambungkan ke satu atau lebih sumber data

Transform: Bersihkan & ubah data menggunakan Power Query Editor

Relate: Bangun hubungan antar tabel

Calculate: Tambahkan perhitungan untuk memperkaya model

Setelah semantic model siap, kamu bisa mulai membangun laporan dari model tersebut.

📊 2. Membuat Visualisasi
Di Power BI Desktop, kamu bisa membuat visualisasi (visuals) langsung di kanvas laporan:

Gunakan metode drag-and-drop data ke kanvas

Power BI otomatis memilih jenis visualisasi awal

Kamu bisa bebas mengganti jenis visual, menambah/mengurangi fields sesuai kebutuhan

📌 Tips desain laporan:

Satu halaman = data yang saling terkait (jangan terlalu padat)

Gunakan interaktivitas antar visual (misal: filter berdasarkan klik pengguna)

Gunakan fitur drillthrough untuk menampilkan detail lebih lanjut

Gunakan fitur AI visuals jika ingin insight otomatis

🧩 3. Membuat Dashboard
Setelah laporan selesai dan dipublikasikan ke Power BI Service, kamu bisa membuat dashboard.

🔹 Dashboard adalah halaman tunggal yang terdiri dari tile (potongan visual laporan).
🔹 Tile bisa dipasang (pinned) dari laporan, tapi tidak interaktif secara langsung.
🔹 Jika pengguna mengklik tile, mereka akan diarahkan ke laporan aslinya.

📌 Dashboard cocok untuk:

Menyediakan ringkasan informasi penting

Menjadi "overview cepat" seperti dashboard mobil

Menyediakan akses ke detail data via laporan

🔁 Kesimpulan Alur Power BI
Langkah	Deskripsi
🔌 Connect	Sambungkan ke sumber data
🧹 Transform	Bersihkan & bentuk data
🔗 Model	Bangun relasi & kalkulasi
📄 Report	Buat visual & laporan
☁️ Publish	Publikasikan ke Power BI Service
📋 Dashboard	Buat ringkasan visual dari laporan
